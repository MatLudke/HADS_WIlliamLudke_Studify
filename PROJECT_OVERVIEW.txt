1. PROJECT DESCRIPTION & PURPOSE
================================================================================

Studify is a comprehensive study management and productivity application 
designed for high school and university students. The platform helps students 
organize their study activities, track time using the Pomodoro technique, 
set and monitor learning goals, generate AI-powered flashcards, and review 
their study performance through detailed reports and analytics.

TARGET AUDIENCE:
- High school students preparing for exams
- University students managing coursework
- Self-learners tracking study progress
- Anyone seeking to improve study habits and time management

CORE VALUE PROPOSITION:
- Structured study time management with Pomodoro timer
- Goal setting and progress tracking (daily/weekly/monthly)
- AI-generated flashcards in multiple languages
- Performance analytics and session history
- Email reminders for goal accountability
- Cross-device responsive design

8. SETUP INSTRUCTIONS
================================================================================

8.1 PREREQUISITES
-----------------
- Node.js 20+ (specified in .idx/dev.nix)
- npm or yarn package manager
- Firebase project account
- Poe API key (for flashcard generation)
- EmailJS account (optional, for notifications)

8.2 INSTALLATION STEPS
----------------------
1. Clone the repository:
   git clone [repository-url]
   cd ExportingFromFIrebaseStudio

2. Install dependencies:
   npm install

3. Configure environment variables:
   Copy .env.example to .env.local
   Fill in the following values:

   # Firebase Configuration
   NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
   NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_auth_domain
   NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
   NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_storage_bucket
   NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
   NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
   NEXT_PUBLIC_FIREBASE_MEASUREMENT_ID=your_measurement_id

   # App Configuration
   NEXT_PUBLIC_APP_URL=http://localhost:9002

   # Poe API (for flashcards)
   POE_API_KEY=your_poe_api_key

   # EmailJS (optional)
   NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_service_id
   NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=your_template_id
   NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=your_public_key

4. Run development server:
   npm run dev
   
   Server starts on: http://localhost:9002

5. Build for production:
   npm run build
   npm start

8.3 FIREBASE SETUP
------------------
1. Create Firebase project at https://console.firebase.google.com
2. Enable Authentication:
   - Google Sign-In provider
   - Email/Password provider
3. Create Firestore database:
   - Start in production mode
   - Set security rules (see section 8.4)
4. Get Firebase config from Project Settings
5. Add config to .env.local

8.4 FIRESTORE SECURITY RULES (NOT INCLUDED)
--------------------------------------------
You must configure these rules in Firebase Console:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Activities - users can only access their own
    match /activities/{activityId} {
      allow read, write: if request.auth != null && 
        request.auth.uid == resource.data.userId;
    }
    
    // Study sessions - users can only access their own
    match /studySessions/{sessionId} {
      allow read, write: if request.auth != null && 
        request.auth.uid == resource.data.userId;
    }
    
    // Active sessions - users can only access their own
    match /activeSessions/{sessionId} {
      allow read, write: if request.auth != null && 
        request.auth.uid == resource.data.userId;
    }
    
    // Flashcard sessions - users can only access their own
    match /flashcardSessions/{sessionId} {
      allow read, write: if request.auth != null && 
        request.auth.uid == resource.data.userId;
    }
    
    // User preferences
    match /users/{userId} {
      allow read, write: if request.auth != null && 
        request.auth.uid == userId;
    }
  }
}
```

10. KNOWN ISSUES & LIMITATIONS
================================================================================

10.1 CURRENT LIMITATIONS
------------------------
⚠️ No offline support (requires internet connection)
⚠️ Poe API key required (not free tier)
⚠️ Email reminders require EmailJS account
⚠️ No mobile app (web only)
⚠️ No data export for flashcard history
⚠️ Language detection not persistent (resets on page reload)
⚠️ Timer sound not customizable
⚠️ No collaboration features (single-user only)
⚠️ No calendar view for study sessions
⚠️ Limited to 12 languages (no dynamic addition)

10.2 KNOWN BUGS
---------------
✅ FIXED: AnimatePresence warning with mode="popLayout"
✅ FIXED: Flashcard overlap at 100% zoom
✅ FIXED: Session not saving on timer completion
✅ FIXED: Language detection causing re-renders

Remaining:
❓ Potential race condition in active session cleanup
❓ Timer may drift slightly due to setInterval precision
❓ Email reminders throttling uses localStorage (not cross-device)
❓ Goal period calculations may be inaccurate near DST changes
❓ Large datasets (1000+ sessions) may cause performance issues

10.3 BROWSER COMPATIBILITY
--------------------------
✅ Chrome 90+
✅ Firefox 88+
✅ Safari 14+
✅ Edge 90+
⚠️ Internet Explorer: NOT SUPPORTED
⚠️ Older browsers may have animation issues

10.4 SECURITY CONSIDERATIONS
-----------------------------
⚠️ Firestore security rules NOT included in repository
⚠️ API keys in .env.local must be kept secret
⚠️ Email addresses exposed in EmailJS (consider server-side solution)
⚠️ No rate limiting on flashcard generation (cost concern)
⚠️ No input sanitization on flashcard subjects (potential XSS)
